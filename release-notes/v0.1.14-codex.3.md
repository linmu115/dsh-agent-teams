# v0.1.14-codex.3

## DSH 0.1.2-alpha.2

- Replaced the removed runtime `settingsNamespace()` helper with the literal
  namespaces accepted by Alpha.2's public `ctx.settings.register()` API.
- Removed the deleted `@deepseek-ai/dsh-client-runtime` client injection and
  dependency declarations. Session lists now come from Session Controller,
  observables from Client Store, and Chat/Conversation node types from their
  owning UI packages.
- Switched the team card registry from the removed `conversationEvents` service
  to `ctx.uiConversation.events`, and loaded Alpha.2's split Renderer/Session
  declarations for slot registration and session-scoped props.
- Updated the continuation verification fixture to Alpha.2's version 3
  `subagent/descriptor` contract; unsupported old descriptor versions remain
  governed by the Harness rather than silently reinterpreted by this plugin.
- Moved `JsonValue` to its new owner, `@deepseek-ai/dsh-util-values`.
- Moved the development baseline to the npm-published Alpha.2 packages so the
  host, client, settings, subagent, and tool contracts are checked together.
- Opened DSH peer ranges to runtime capability resolution instead of blocking
  experimental version combinations at package-install time.
