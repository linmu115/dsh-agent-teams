# v0.1.14-codex.4

## DSH 0.1.2-rc.1

- Moved the development and build baseline from DSH `0.1.2-alpha.2` to
  `0.1.2-rc.1` without narrowing the plugin's runtime peer ranges.
- Replaced the removed `Session.events.slice(header.seedLength)` access with
  RC1's `Session.ownEvents()`. Member setup still folds only the child's own
  durable descriptor events, without reinterpreting inherited history.
- Moved continuable-member setup from the removed
  `subagents.registerContinuableSetup()` hook to RC1's `agent/created`
  lifecycle. The initial provider, model, and reasoning effort are now passed
  through `startContinuable().request.agentOptions`, so RC1 persists and
  restores them in its native continuable descriptor.
- Replaced the removed `subagents.followup()` entry point with RC1's public
  `subagents.sendMessage()` API, including the retired-member guard.
- Removed the obsolete `httpServer` / `workspace` service-key probes. The web
  activity surface now binds only RC1's `webServer` and `workspaceRegistry`.
- Kept the Manager settings, per-member model selection, fallback routing,
  retirement boundary, and cold-resume behavior unchanged. No compatibility
  branch for older DSH session or Subagent shapes is retained.
